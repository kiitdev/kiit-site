Welcome! This is where updates on the Kiit framework and its modules will show up going forward:
design decisions, release notes, and the occasional deeper dive into how a module works.

{/* truncate */}

To start, there are three modules worth knowing about:

- **Kiit Framework** — the overall project this all lives under.
- **[kiit-codes](/docs/kiit-codes)** — a status and error taxonomy for application outcomes.
- **kiit-result** — a `Result<T, E>` type built on top of that same taxonomy.

More posts coming soon.
